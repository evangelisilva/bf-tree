# Benchmark Scripts

Run from the `benchmark/` directory.

## Insert Key Size Sweep
```bash
./run_insert_key_size_sweep.sh
```
Output: `/tmp/benchmark_insert_key_size_sweep.csv`

## Insert Record Count Sweep
```bash
./run_insert_record_count_sweep.sh
```
Output: `/tmp/benchmark_insert_record_count_sweep.csv`

./run_lookup_zipf_uniform.sh
