# Benchmark Scripts

Run from the `benchmark/` directory.

## Insert Key Size Benchmark 
```bash
./run_insert_key_size_sweep.sh
```
Output: `/tmp/benchmark_insert_key_size_sweep.csv`

## Insert Record Count Benchmark
```bash
./run_insert_record_count_sweep.sh
```
Output: `/tmp/benchmark_insert_record_count_sweep.csv`

## Lookup Zipf Uniform Benchmark
```bash
./run_lookup_zipf_uniform.sh
```
Output: `/tmp/benchmark_lookup_zipf_uniform.csv`

## Lookup Zipf Skewed Benchmark
```bash
./run_lookup_zipf_skewed.sh
```
Output: `/tmp/benchmark_lookup_zipf_skewed.csv`
